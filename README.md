# Dave Gorden & Associates — davegorden.net (demo)

Guest Astonishment speaker site. Three static pages, no build step:

- `index.html` — **concept A** landing (dark pine + brass): the Internal/External Guest idea, diagnosis-first framing, industries, contact form
- `b.html` — **concept B** landing (bone + ink + oxblood): photo-forward editorial alternative, sticky mobile call bar
- `programs.html` — the Discovery Visit, four programs, the Pigeon Forge case study, logistics
- `about.html` — hands-on story, philosophy, reach
- `404.html`, `assets/styles.css` (A), `assets/styles-b.css` (B), `assets/dave-gorden.jpg`, `assets/dave-gorden-portrait.jpg`

A fixed **Concept A | B** pill (bottom-left) flips between the two homepages — demo only, remove at launch.

Demo concept by [60minutesites.com](https://60minutesites.com). See `DEMO-NOTES.md` for placeholders, client asks, and the launch checklist.
